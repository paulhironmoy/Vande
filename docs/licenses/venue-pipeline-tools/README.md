# Venue pipeline tools (ASSETS-VENUE, 2026-11-08)

Tools used to MAKE the venue assets (the baked venue packs, the Unity files and the hero plates). None of them is linked into or shipped with the game:
the shipped files are the outputs. Every shipped file is VANDE original: generated by the scripts named in docs/ASSET_REGISTER.md ("Venue, hero plates
and crowd") with fixed seeds; no downloaded model or texture, no Mixamo, nothing from ANT CRICKET or any rival, no AI-generated pixels.

The venue reader (`src/render3d/three/venueGlb.ts`) is VANDE's own code; it reads glTF 2.0 binary files with KHR_mesh_quantization,
KHR_materials_unlit and EXT_texture_webp and uses no glTF library. The Draco and KTX2 decoders are not used (their measured cost is in
release/product-sequence/stage-3-chase/ASSETS-VENUE/measure/decoder-costs.txt).
