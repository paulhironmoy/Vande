# Intentionally incomplete ProjectSettings

`ProjectVersion.txt` is omitted until the owner selects and installs an exact
Unity 6000.3.x LTS patch. The opt-in Android build reads that exact generated
version and requires it to match `Application.unityVersion` reported by
`unity.ready`. Unity-generated settings must be reviewed after the first open;
this source scaffold does not claim to be an exported or tested project.
